# Séance 1 — Ressources

## Outils à avoir avant de commencer
- `curl` (inclus dans Windows 10+, macOS et Linux) : `curl --version`
- `jq` pour lire du JSON : <https://jqlang.github.io/jq/download/> (facultatif mais très pratique)
- Un dépôt Git vide pour le projet Orbitale (GitHub ou GitLab), cloné sur ton poste

## Fichiers
| Fichier | Rôle |
|---|---|
| `memo_http.md` | Méthodes, codes de statut, en-têtes : la fiche à garder ouverte toute l'année |
| `commandes_tp.md` | Les commandes `curl` du TP guidé, prêtes à copier |
| `modele_ressources.md` | Le modèle du livrable `docs/ressources.md` |

## Livrable
Copie `modele_ressources.md` dans ton dépôt sous `docs/ressources.md`, complète-le, puis pousse-le.
